# ✦ LUMIÈRE LABS — Brand Identity & Design System

*"Glow From Within"*

LUMIÈRE LABS is a luxury, minimalist makeup brand focused on clean, dermatologist-tested, and cruelty-free formulas designed to enhance natural beauty.

---

## 🎨 Visual Identity & Color Palette

| Color Name | Hex Code | Purpose |
| :--- | :--- | :--- |
| **Rose Quartz** | `#F7E1D7` | Background & Soft Packaging |
| **Champagne Gold** | `#D4AF37` | Logo Foil & Premium Accents |
| **Warm Nude** | `#E5D3B3` | Primary Compacts & Bottles |
| **Deep Bronze** | `#4A3B32` | Elegant Typography |
